# Mersin Cheff Tantuni — Menü Sitesi
1. Bu klasörün içeriğini GitHub reposuna yükleyin.
2. Settings → Pages → Branch: `main` / root → Save.
3. Fiyat, içerik ve fotoğraf yollarını yalnızca `menu-data.js` içinden düzenleyin.
4. Fotoğrafları `images/products/...` klasörüne, `menu-data.js`'teki dosya adlarıyla kaydedin.
